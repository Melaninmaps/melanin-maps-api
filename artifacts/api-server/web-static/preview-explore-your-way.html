Interactive app concept

Open what you need.
Leave when you’re done.

The navigation is deliberately direct. You can browse nearby food, find a vibe, explore an event, save a community post, look for housing, or begin a healthcare search—then stop there. Kinfolk is available when the need becomes more connected.

Direct use: every bottom-navigation route is tappable.
Clear return path: detail screens expose an in-app back arrow and tappable page title.
Honest preview: cards are illustrative; no listing, event, report, booking, provider, or saved item is live.
