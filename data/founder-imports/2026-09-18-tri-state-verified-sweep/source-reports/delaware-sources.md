## Method and limitations

Each included row has a public street address from a source page, except rows intentionally omitted when the source supplied only a service area or P.O. box. Official websites are recorded only where the source page supplied one; no ownership, ethnicity, language, hours, accessibility, licensing, or services were inferred. Source directory entries were reviewed directly rather than relying on search snippets. Existing-system duplicate checking was not possible because production systems were not accessed; rows should be compared against the system during later enrichment. The resulting inventory is a careful initial sweep, not a comprehensive census, and the Latino/Hispanic segment needs a second pass through the interactive DeHCC and DALE directories.
