# Source report: Virginia Hispanic Chamber directory

## Conclusion

One candidate is retained from the publicly accessible individual listing page inspected. No ownership designation is assigned because the chamber directory context is not proof of business-owner identity, and the individual profile does not publish a Latino/Hispanic ownership claim.

## Source and pages inspected

The independent source family was the **Virginia Hispanic Chamber Products & Services Guide**, presented on DocuTeam/Chamber Nation. The chamber’s directory landing page identifies the directory as a search for local businesses and gives Central Virginia coverage and a Richmond office address [1]. The chamber homepage identifies the organization and links to its member directory [2]. The directory platform page was inspected directly [3], as were alphabetized directory URLs for A, P, and T [4] [5] [6]. Those platform pages returned the directory shell and privacy content rather than usable listing rows in this collection environment.

The one individual profile that was publicly inspectable was **Abbate Agency - Knights of Columbus** [7]. Its page publishes the business name, a direct official website link, phone number, and the numbered address **4118 E. Parham Rd., Richmond, Virginia 23228, US**. It also states that the agency is family run and names Bob Abbate as founder. That founder statement is retained only as a factual note; it is not converted into a current ownership designation.

## Routing and destination controls

The retained record uses `targetKind: business` because the inspected profile is a commercial agency listing with a numbered address and a direct customer-facing official website. The directory homepage and chamber social links were not used as customer destinations. No community-resource or cultural-place records were created because no individually inspected source page supplied a qualifying nonprofit, house of worship, school, museum, or community-organization listing with the evidence needed by the contract. No Latino/Hispanic ownership claim was added.

## Pagination and limits

The source landing page and the A, P, and T alphabetized URLs were inspected. The directory platform did not expose listing rows or reliable pagination controls in the returned public HTML, so hidden pages were not guessed. Search-result snippets were not used as sole evidence. One direct individual profile was opened and inspected. The candidate file contains one row; the held file contains zero rows.
