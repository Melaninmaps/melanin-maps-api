## Duplicate and file validation

A feasible exact duplicate audit was run against all local `*.jsonl` research under `/home/ubuntu/directory-research-wave-2026-09-18/`. It normalized **name + city + state + address** by lowercasing and removing non-alphanumeric characters, then compared each prospective key with the existing local keys. The audit examined 2,691 existing JSONL records and found no exact match for any retained or held Nashville-wave candidate. All lines in both output JSONL files were parsed as JSON after writing.

## Limitations

This is a finite source pass, not a census. Directory membership supports inclusion but does not certify ownership. Some public sources provided only P.O. boxes, temporary event venues, a city-level description, or no address; mapless treatment is limited to qualifying community resources, while a commercial provider without a current numbered physical address is held. A public site’s services, events, statements, and social links are recorded only as presented; no facts were inferred about ownership, protected traits, language/bilingual capability, licensing, health outcomes, price, hours, availability, accessibility, operations, coordinates, pins, or directions. Two Chamber-linked destinations did not resolve and remain held; Moleiro Productions remains held for missing current numbered street address.

**Research-only status:** not staged, not published, and not deployed.
