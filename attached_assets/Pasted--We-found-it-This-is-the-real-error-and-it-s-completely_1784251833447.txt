# What it means

Expo/CocoaPods is trying to install a library called:

**`react-native-google-maps`**

…but that library **doesn't exist** where CocoaPods expects it.

Notice what it's looking inside:

```
react-native-maps
```

It is **inside `react-native-maps`** trying to find a pod named **`react-native-google-maps`**, and it can't.
