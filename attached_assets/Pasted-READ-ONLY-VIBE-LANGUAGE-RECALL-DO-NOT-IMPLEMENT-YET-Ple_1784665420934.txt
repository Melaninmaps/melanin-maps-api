When another build would be required
A new build is needed if the correction involves native iOS configuration, such as:
adding or changing a native Maps SDK key
changing app.json map configuration
installing or changing the map library
modifying iOS permissions or native plugins

incorrect API endpoint
JavaScript rendering logic
loading-state behavior
business or cultural-site data handling
timeout and retry logic
