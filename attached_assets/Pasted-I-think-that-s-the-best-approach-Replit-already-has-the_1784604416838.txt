**Authentication impact:** NONE

**Code changes:** NONE

**Deployments:** NONE

**Database changes:** NONE

Run the existing production database probe using the **production** `DB_PROBE_KEY` and determine whether the production API process can successfully execute a database query.

## Requirements

1. Use the **production** `DB_PROBE_KEY` from the Railway API service.

```
GET https://www.mappingwithmelanin.com/api/db-probe
```

with the required `x-probe-key` header.

3. Return the complete JSON response (redact secrets if necessary).

4. If the probe fails, return:

   * HTTP status
   * response body
   * timeout duration (if applicable)
   * any runtime exception

   * error name
   * error code

* Registration
* Login
* `/api/businesses?limit=1`

and identify exactly which query or endpoint hangs.

## Evidence Required

Do not infer the cause.

Support every conclusion with:

* runtime logs,
* probe output,
* or production responses.

Do not declare a root cause without direct runtime evidence.
