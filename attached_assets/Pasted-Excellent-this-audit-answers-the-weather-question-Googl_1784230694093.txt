## Important correction to Replit’s suggestion

The backend Directions key cannot be protected with website/referrer restrictions because the request originates from the Replit server—not the user’s browser.

Therefore:

* Web key: website restrictions
* Android key: Android application restrictions
* Server key: IP restriction if Replit provides a fixed outbound IP; otherwise Directions-only API restriction, quotas, billing alerts, and secret server-side storage

Also, I would avoid authorizing every `*.replit.app` website if we can use your exact Replit production address. A broad wildcard would allow the key to be used from other Replit-hosted sites if it were copied.
