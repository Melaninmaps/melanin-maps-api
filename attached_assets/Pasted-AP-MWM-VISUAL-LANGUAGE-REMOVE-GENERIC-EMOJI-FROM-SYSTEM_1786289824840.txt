AP. MWM VISUAL LANGUAGE — REMOVE GENERIC EMOJI FROM SYSTEM UI

FOUNDER DESIGN DECISION:

Mapping With Melanin™ should NOT use ordinary/basic emoji as system-generated interface artwork.

Members may absolutely use emoji in:
- posts
- comments
- stories
- reviews
- messages
- captions
- other user-generated content

But MWM-controlled UI should use the approved Mapping With Melanin visual language.

- briefcase
- shopping bags
- handshake
- shield
- heart
- graduation cap

=========================================================
CROSS-PLATFORM CONSISTENCY
=========================================================

The mobile web and desktop web should use the SAME icon family.

Do not use:
emoji on mobile
custom icons on desktop

for the same concept.

Use responsive sizing of the same MWM visual asset.

=========================================================
IMPLEMENTATION PREFERENCE
=========================================================

Where possible, use reusable SVG/icon components rather than separate raster images for every screen so:

- scaling remains sharp
- gold treatment stays consistent
- mobile/desktop can share assets
- accessibility labels can be added
- future visual updates can happen centrally

Do not expose or distribute proprietary source design assets unnecessarily.

=========================================================
ACCESSIBILITY
=========================================================

Decorative icons:
aria-hidden / equivalent

Functional icons:
must have accessible label/tooltips where needed

Do not rely on icon shape alone when meaning is important.
