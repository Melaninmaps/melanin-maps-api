3. MAPS — REQUIRED IN THIS RELEASE
══════════════════════════════════════════════════════════════

Maps are required. They are not deferred.

Testers must be able to open the Map and receive meaningful results.

Required map experience:

A. BUSINESS DISCOVERY

- Existing businesses displayed
- Business-category tabs work
- Categories can scroll horizontally
- Results can scroll vertically
- Search works
- Result counts are correct
- Selecting a result shows a brief tile
- Selecting a marker highlights the corresponding result
- Business name
- Business type/category
- Short description
- Location
- Ownership/community designations when supported
- Vibes and experience tags when already built
- Website or external link where currently supported
- Missing optional fields do not crash the screen

B. HERITAGE PLACES

- Heritage category available and visible
- Heritage places load
- Heritage-category tabs work
- Search works
- Results and markers synchronize
- Each tile includes:
  - Name
  - Location
  - Brief historical or cultural description
  - Category
  - Available source information
  - Website/link where already supported
- Freedom Trail category included where current data supports it
- Empty states are meaningful
- Heritage content must feel intentional, not like placeholder data

C. HISTORICAL SUNDOWN TOWNS

Include a user-selectable Map layer named:

“HISTORICAL SUNDOWN TOWNS”

This layer must clearly distinguish historical context from current
conditions.

Minimum release experience:

- State-based browsing
- Search by place
- Map marker
- Place name
- State
- Historical evidence/status
- Brief sourced description
- Source attribution
- Clear disclaimer
- “Learn More” path or source link where available

Potential historical statuses:

- Historically confirmed
- Probable or strongly documented
- Possible or still being researched
- Disputed or incomplete information

Required disclaimer concept:

“This location appears in historical research concerning sundown towns—
communities that excluded Black people or other racial, ethnic, or
religious groups through law, intimidation, custom, or violence. This
historical designation is not, by itself, a statement about every current
resident or a definitive assessment of present-day conditions.”

Do not:

- Call every historical location currently dangerous
- Display an unsupported current safety score
- Present one report as a community-wide conclusion
- Combine historical records and current reports into one number
- Use demographics as a proxy for danger
- Make route-avoidance decisions automatically

If recent MWM reporting volume is not sufficient for responsible trends,
show the historical layer now and clearly label current information as
insufficient.

D. MAP PERFORMANCE

The Map must not load an unsafe number of markers simultaneously.

Use as appropriate:

- Marker clustering
- Viewport/bounding-box loading
- State-based lazy loading
- Result limits
- Progressive loading
- Cached historical records
- Layer isolation
- Safe failure states

Test rapid switching among:

- Businesses
- Heritage
- Historical Sundown Towns

One failed layer must not crash the entire Map.

5. KINFOLKAI — BASIC USEFUL TESTER EXPERIENCE
══════════════════════════════════════════════════════════════

KinfolkAI must remain in the builds and provide useful basic chatbot
functionality now.

This is not authorization for the full future-state Community Operating
System.

Minimum required capability:

- Open KinfolkAI
- Ask a general question
- Receive a coherent answer
- Ask a follow-up
- Maintain current conversation context
- Answer basic planning and informational questions
- Provide basic travel and local discovery support
- Recommend businesses or heritage places when relevant and supported by
  platform data
- Respect saved user preferences that are already implemented
- Respect current tone/voice preferences where already implemented
- Load conversation history where currently supported
- Handle limits transparently
- Handle provider timeout or failure without crashing

Examples KinfolkAI should handle:

- “What should I do in Philadelphia this weekend?”
- “Help me find a family-friendly restaurant.”
- “What heritage places should I visit?”
- “Are there historical sundown towns near my route?”
- “Help me plan a quiet day with museums and parks.”
- “How much do televisions usually cost?”
- “What should I pack for a trip?”
- “What is the weather where I am going?”

WEATHER REQUIREMENT:

If a current approved weather service is already connected, use it and
identify the location and timing of the information.

If no live weather source is connected, KinfolkAI must not invent current
weather. It should clearly explain that live weather is unavailable and
offer planning guidance based on user-provided conditions or direct the
member to an appropriate live source.

KinfolkAI may intuitively promote minority-owned or culturally relevant
businesses when:

- The recommendation genuinely applies
- Platform data supports the business
- The member’s preferences support it
- The result is clearly explained
- Organic and sponsored placement remain distinguishable

KinfolkAI must not:

- Invent business information
- Claim current facts without a source
- Overpromise safety
- Use stereotypes
- Force promotion into unrelated answers
- Fail silently
- Expose raw provider or server errors

Test KinfolkAI on:

- Web
- iPhone
- iPad
- Android phone
- Android tablet

Verify keyboard, scrolling, response loading, follow-ups, timeout handling,
and background/resume behavior.
