Yes — **relevance is exactly the connection.** The Library should not be a static encyclopedia where “Historical Churches” only shows generic articles. It should dynamically connect **what the topic means + where the user is + what entities MWM already knows about + what the user is trying to do.**

So if you open:

**Library → Faith, Spirituality & Community → Historical Churches**

while you are in Philadelphia, the experience should absolutely be capable of surfacing a historically significant Black church already listed in MWM as a relevant local entity.

The connection should happen through shared metadata and relationships, not by hard-coding “Philadelphia church X belongs on this page.”

For a place/entity already in MWM, Replit should make sure it carries structured fields such as:

**Entity type:** House of Faith / Historical Site
**Faith tradition:** Christian / denomination if known
**Cultural significance:** Black history / African American history
**Historical significance:** yes
**Location:** Philadelphia, Pennsylvania
**Topics:** Historical Churches, Black Church History, Civil Rights, Faith & Community
**Library relationships:** relevant Books/Collections
**Map coordinates:** latitude/longitude
**Sources:** authoritative history/official institution source
**Current operating status:** active / historic / both

Then when the user opens **Historical Churches**, the Library ranks connected entities by relevance.

I would use a relevance order like:

**1. Exact topic match**
A place explicitly tagged/related to Historical Churches.

**2. Location relevance**
If the user is in Philadelphia, Philadelphia results rise first.

**3. Cultural relevance**
Black church history, African American heritage, historic faith institutions, etc.

**4. Historical significance**
Founding date, documented “first,” civil-rights role, major community significance.

**5. User intent/context**
If they are planning a trip to Philadelphia, use the trip destination rather than their physical home location.

**6. Community intelligence**
Saved by members, visited, stories/videos contributed, community trust—without letting popularity erase historical importance.

**7. Source quality**
Well-sourced historical entities should rank above poorly documented records.

That means the page could feel like:

And if you are physically in Houston but planning Philadelphia, Kinfolk/Library should understand:

> **Current location: Houston**
>
> **Current trip context: Philadelphia**

and prioritize Philadelphia because that is the relevant context.
