One important distinction: tell Replit exactly which Apple action you want.

If this is still a **beta build for external testers**, Replit should upload it to App Store Connect/TestFlight, then you may still need to select Build 90 in the external testing group and submit it for Beta App Review.

If you mean the **public App Store release**, that is a different submission and requires the App Store version page, review information, screenshots, pricing, and release settings to be complete.

Based on your current wording, I would have Replit **upload Build 90 to App Store Connect first**, then confirm what manual TestFlight or App Review step remains after processing.

For Android, wait until Version Code 64 finishes, install and smoke-test it, then upload it manually to the intended Google Play track.
