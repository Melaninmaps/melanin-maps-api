══════════════════════════════════════════════════════════════

connection is released.

- pool.connect()

- Promise.race around database operations
- long transactions
- streaming queries
- event listeners holding clients
- health monitors acquiring but not releasing clients

- session-store pool misuse

- acquisition source
- acquisition time
- release time
- pool total
- pool idle
- pool waiting
- connections older than the allowed threshold

enough to exceed the previous 65-minute leak window.

A test shorter than the former failure window is not sufficient.
