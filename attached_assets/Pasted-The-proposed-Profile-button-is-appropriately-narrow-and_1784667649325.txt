## Use the production channel, not only the branch

Build 94 is subscribed to the `production` **channel**. Current Expo guidance recommends publishing to that channel and explicitly selecting the production EAS environment. ([Expo Documentation][1])

Use:

```bash
cd artifacts/mobile

eas update \
  --channel production \
  --environment production \
  --platform ios \
  --message "PR-A: Add admin map diagnostic entry"
```

This is preferable to:

```bash
eas update --branch production
```

A branch can be linked to a channel, but publishing through `--channel production` directly targets the channel embedded in Build 94 and avoids relying on an assumed branch-channel mapping. ([Expo Documentation][2])
