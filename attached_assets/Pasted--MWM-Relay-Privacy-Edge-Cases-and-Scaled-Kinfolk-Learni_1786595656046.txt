### k-10 / Laplace edge case

The SQL makes the behavior strict:

| Weekly bounded distinct count | Result |
| ---:| --- |
| 0–9 | Fully suppressed. No noise, no rounded value, no candidate, no dashboard metric. |
| 10+ | Release only after the fixed window closes and a 24-hour delay; add one persisted Laplace draw, clamp at zero, and round to five. |

Noise is applied **after** the k=10 eligibility test, so a count of 9 can never be accidentally displayed as 10. The same released metric always returns the same noisy rounded result; refreshes never redraw the noise.
