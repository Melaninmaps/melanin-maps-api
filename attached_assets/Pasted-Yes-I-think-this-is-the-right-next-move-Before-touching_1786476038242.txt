The specific thing I want to learn from Replit is whether the Library is truly **inside Kinfolk's retrieval path** or merely sitting beside it.

Because those are very different products.

If today the architecture is effectively:

**User → Kinfolk → OpenAI**

with a few business/preferences injected, while the Library sits in another part of the application, then that explains why you can have hundreds of Library topics and still not feel that Kinfolk is becoming more knowledgeable.

What we actually want eventually is closer to:

**User question → understand intent → retrieve MWM business/community/Library/Knowledge Graph evidence → add personalized context → use AI to synthesize → answer with provenance → user acts/contributes → those signals enrich MWM → next answer gets better.**

And the flywheel only exists if the **last arrow actually comes back around**. If someone saves a place, follows IVF, adds a vibe, contributes a Bangkok video, or leaves a review and none of those signals meaningfully influence future discovery or Kinfolk, then we have pieces of a flywheel but not yet a functioning flywheel.

That architecture report should tell us exactly where the loop breaks.
