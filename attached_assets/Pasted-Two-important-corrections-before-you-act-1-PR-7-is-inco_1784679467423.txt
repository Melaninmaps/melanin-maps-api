Build 94 is subscribed to the **production channel**. The `pool-fix-validation` branch is not linked to that channel, so simply opening an EAS dashboard link will not make your TestFlight build load it.

Expo confirms that builds receive updates through their embedded channel, and the channel points to a branch. An unlinked validation branch is useful to prove that bundling succeeded, but a normal TestFlight production build will not receive it automatically. ([Expo Documentation][1])

To test that exact validation update before production, you would need one of these:

* a development build that can open arbitrary branches,
* a separate preview/staging build whose channel is linked to the validation branch,
* or a channel-switching mechanism already built into the app. ([Expo Documentation][2])
