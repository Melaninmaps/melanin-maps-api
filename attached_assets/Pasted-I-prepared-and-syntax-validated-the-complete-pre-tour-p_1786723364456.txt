## Run the pre-tour health gate

After Replit creates a dedicated monitoring account and stores its credentials securely:

```bash
export BASE_URL='https://api-server-production-a991.up.railway.app'
export MWM_MONITOR_EMAIL='dedicated-monitor@example.com'
export MWM_MONITOR_PASSWORD='read-from-secret-vault'
python3 mwm_pre_tour_health_check.py > mwm-pre-tour-result.json
status=$?
cat mwm-pre-tour-result.json
exit $status
```

The deployment is green only if the output ends with:

```json
"result": "PASS"
```

Do not use the 30 beta accounts for monitoring. Replit must configure email plus a mobile-capable channel such as SMS, push, Slack, Discord, or PagerDuty. Critical alerts trigger after three consecutive failures or any five consecutive 5xx responses. KinfolkAI degraded alerts trigger when the rolling 15-minute degraded rate is **greater than 5% with at least 20 requests**.

The Python health script passed syntax validation. The telemetry patch also includes an important production note: if Railway runs more than one application instance, the in-memory rolling counter must be replaced with shared metrics, Redis, or the project’s observability system.
