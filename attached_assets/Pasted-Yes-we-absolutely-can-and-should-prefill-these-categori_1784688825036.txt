## What each prefilled record should contain

Every site should include:

* official name
* category and subcategory
* city and state
* full address
* latitude and longitude
* short description
* historical significance
* official website
* image or image reference
* source used to verify the information
* verification date
* accessibility information when known

The descriptions should be factual and sourced—not generated as unsupported history.
