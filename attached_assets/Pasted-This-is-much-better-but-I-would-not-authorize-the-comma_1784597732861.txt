## 1. Do not use `--auto-submit`

Their proposed iOS command is:

```bash
eas build --platform ios --profile production --auto-submit
```

That would automatically upload the build to App Store Connect after it finishes. You have not physically verified that the map works yet, so Apple submission should remain a separate action.

Use:

```bash
eas build --platform ios --profile production
```

Then:

1. Wait for Apple to process it.
2. Install it through TestFlight.
3. Confirm the map visibly works.
4. Run the login/logout and Kinfolk checks.
5. Only then upload or submit the approved build.
