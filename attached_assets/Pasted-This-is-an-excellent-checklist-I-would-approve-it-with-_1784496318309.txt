## Add one new section: Navigation & Session Stability

These are based on the issues you discovered today.

### NAVIGATION & SESSION STABILITY

* [ ] Back, Cancel, or Close is available on every modal, form, and multi-step screen.
* [ ] iOS swipe-back gesture works where appropriate.
* [ ] Android system back button behaves correctly.
* [ ] No authenticated action unexpectedly redirects to the login screen.
* [ ] Failed API requests (500, timeout, network error) do **not** sign the user out.
* [ ] Only an explicit invalid-session response (401) clears the stored session.

## My last recommendation

At the very end, I would add one final check that often catches subtle issues:

### Overall Experience

* [ ] **Spend 15 uninterrupted minutes using the app naturally without following a script.**

  * Browse.
  * Search.
  * Save.
  * Ask KinfolkAI™ questions.
  * Open profiles.
  * Switch tabs.
  * Leave and return to the app.

The goal is to answer one question:

> **"Does anything make me stop and think about the app instead of what I'm trying to accomplish?"**

That kind of unscripted use often reveals friction that targeted tests miss.
