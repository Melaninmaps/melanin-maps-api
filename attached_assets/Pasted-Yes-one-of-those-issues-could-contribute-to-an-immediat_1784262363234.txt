## There could absolutely be something else wrong

An app that installs successfully and closes immediately can also be caused by:

* a JavaScript exception during startup,
* a missing production environment variable,
* authentication initialization failure,
* an incompatible native module,
* a bad OTA update,
* a missing iOS permission or configuration,
* or code that works in development but fails in a production build.

Expo notes that an exception occurring before the React Native application registers is a common reason an app fails immediately during launch. ([Expo Documentation][2])
