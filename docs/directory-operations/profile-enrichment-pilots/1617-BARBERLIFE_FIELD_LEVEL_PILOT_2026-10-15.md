## What this demonstrates

Yes—this is the workflow you have been asking for. The work is not just “the website exists.” For each eligible record, the process is:

1. Open the business’s own website and relevant internal pages.
2. Compare each useful fact against the current MWM profile.
3. Propose only first-party, field-level additions or corrections with the exact source URL and check date.
4. Keep conflicts on hold instead of overwriting them. This example catches a real address conflict rather than silently changing a map location.
5. Save only the fields you approve under the eventual controlled production-update process, then verify the live profile after saving.

For this record, the safe high-value initial save would be: **description, service tags, website-displayed hours, and call-to-book / walk-in guidance**. The existing website, phone, Instagram, and Facebook do not need replacement. The street address must stay untouched pending confirmation.
