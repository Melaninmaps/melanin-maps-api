# Mapping With Melanin™ — Intellectual Property Framework
## CONFIDENTIAL — INTERNAL REFERENCE
**July 26, 2026**

This document categorizes Mapping With Melanin™ intellectual property into
three tiers: Trademark/Brand, Copyright, and Trade Secrets.

Consult qualified IP counsel before making any public assertions of protection.
This document is a planning reference, not a legal opinion.

---

## Category 1 — Trademark / Brand

Customer-facing names and identities that distinguish the platform.

  Mapping With Melanin™
  KinfolkAI
  Community Understanding (as a named product concept)
  Living Legacy
  Cultural Ambassador (as a platform role)
  Community Health Profile (if adopted consistently as product name)
  Community Insights (Build 97 temporary label)
  Life Journeys (as a named platform feature)
  Kinfolk Circles
  Community Growth Model

Note: Trademark protection requires use in commerce and, for stronger
protection, federal registration. Consult counsel on priority dates.

Original written and creative works authored by or for Mapping With Melanin™.

## Category 3 — Trade Secrets

Internal systems that provide competitive advantage.
Must be maintained as confidential to retain trade secret status.
Requires reasonable security measures (access controls, NDA for partners).

  Community Understanding Engine (signal selection, weighting, methodology)
  Mirror Twin recommendation model (aggregate matching methodology)
  Community Intelligence Engine (orchestration logic)
  Community Reciprocity Engine (timing logic, threshold values)
  Business Opportunity Engine (gap detection criteria)
  Ambassador Impact Engine (communities-served calculation)
  Life Season progression logic (season detection, threshold values)
  Community Health Intelligence Engine (signal selection, weights, tiers)
  Recommendation weighting formulas and priority stack
  Partnership matching criteria
  Ecosystem orchestration logic (cross-engine interaction rules)
  Trust calculation weighting in recommendations
  Opportunity detection criteria (gap identification logic)
  Business coaching methodology (Growth Coach prompt architecture)
  Confidence tier thresholds and corroboration minimums
  Bias prevention threshold values

## What Must Never Be Publicly Disclosed

  Weighting formulas or percentage values for any engine
  Confidence tier threshold values
  Pattern corroboration minimum thresholds
  Mirror Twin matching methodology
  Trust level weighting in recommendation outputs
  Ecosystem orchestration priority rules
  Signal selection criteria for Community Health
  Opportunity gap detection criteria

---

## Security Requirements for Trade Secret Status

  Access restricted to team members with need to know
  NDA required for all partners, contractors, and investors
    who access Category 3 materials
  docs/trade-secrets/ directory must not be publicly accessible
  Internal documentation must be marked CONFIDENTIAL
  Oral disclosures should be minimized; written summaries
    should not include methodology details
