# Business Category-to-Tag Mapping

## Purpose and placement

This mapping prevents irrelevant labels from appearing on business profiles. It uses one unified **Community Says** card. The top layer of that card is either **Vibes** for places people visit and experience, or **The Standard** for professionals and service providers people entrust with expertise, care, money, property, or an important outcome. Quick captions and written feedback appear beneath the top tags in the shared Community Says area.

> **Vibes** answers: “How does this place feel?”  
> **The Standard** answers: “How did this provider show up?”  
> **Community Says** captures the community’s captions, commentary, and social proof beneath either set.

This is a controlled taxonomy, not a single global tag list. A profile should show **six to ten eligible tags** drawn from its category set, not every tag in that set. Businesses may claim profiles and request a category correction, but community feedback must remain community-generated and moderated.

## Tag governance

| Rule | Product requirement |
|---|---|
| Unified location | Display the context-specific tags first inside the one **Community Says** card, in the current Vibes location. |
| Top-layer selection | Use **Vibes** for place-based leisure, hospitality, retail, culture, and public community experiences. Use **The Standard** for expertise-led, care-led, appointment-based, fiduciary, clinical, and outcome-led services. |
| Category gating | Only make the mapped tags available to the business’s primary category and approved secondary category. |
| No unrelated labels | Do not surface a tag merely because it is globally popular. For example, BBQ must never receive a generic **Soft Life** label; an accountant must never receive **Grandma Approved**. |
| Tag limits | Let a contributor choose up to three top-layer tags per visit or service interaction. Rank the profile view by recent, verified, and broadly supported use. |
| Sensitive services | For health, legal, financial, and therapy profiles, prohibit outcome promises, diagnostic claims, and personal-health disclosures in tags. Use respectful service-quality language instead. |
| Shared feedback | Community captions and written comments remain below the top tag layer for every category. |

## Special handling for mixed-use businesses

Some profiles include both a public place and an expert service. The primary booking or discovery intent determines the top layer.

| Example | Default top layer | Rule |
|---|---|---|
| Salon with retail shelves | The Standard | The appointment-based beauty service is primary; retail products stay in the business details. |
| Hotel spa | Vibes | The profile is a leisure destination; service-quality feedback may be captured as Community Says text. |

## Implementation logic

The system should assign `experience_model = vibes` or `experience_model = standard` to every category. Each business profile receives one `primary_category`, optional `secondary_category`, and an approved `tag_pack` from this mapping. Only the primary pack displays by default. If the profile is misclassified, the business can request correction and users can flag the category; moderation approves the taxonomy change.
