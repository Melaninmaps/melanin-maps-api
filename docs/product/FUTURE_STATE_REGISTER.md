# Mapping With Melanin™ — Future-State Register

**Purpose:** Permanent, version-controlled record of every approved idea, proposed capability, founder suggestion, future-state feature, enhancement, policy consideration, and unresolved product decision. Ideas documented here are not rejected — they are preserved for the platform's future.

**Authorization rule:** No entry may be marked REJECTED or SUPERSEDED without an explicit founder decision. "Not being built now" means DEFERRED or PLANNED — never rejected.

**Trigger phrase for implementation:** "Please implement." — any other phrasing is brainstorming only.

**Maintained by:** Replit Agent, updated at the end of every session that identifies new or changed future-state suggestions.

---

## Status Labels

| Label | Meaning |
|-------|---------|
| PROPOSED | Identified and preserved; not yet evaluated for scheduling |
| NEEDS FOUNDER CLARIFICATION | Awaiting a founder decision before status can advance |
| FOUNDER APPROVED | Founder has confirmed the concept and direction |
| DEFERRED | Will not be built in the current phase; preserved for a future one |
| PLANNED | Scheduled for a specific upcoming phase |
| PARTIALLY BUILT | Infrastructure exists (DB schema, API route, or screen); UI or full flow not yet complete |
| IMPLEMENTED | Fully built and active in production |
| TESTING | Built; under QA or acceptance review |
| BLOCKED | Cannot proceed until a dependency is resolved |
| SUPERSEDED | Replaced by a newer approved direction (prior wording preserved as historical reference) |
| REJECTED BY FOUNDER | Explicitly declined by the founder |
