## The Review Framework

Every page carries four sections. No perspective overwrites another.

### How Pages Are Reviewed

**1. Founder Notes** — Does this communicate our vision?
**2. First-Time Audience Notes (Kevin)** — Does this make sense to someone seeing it for the first time?
**3. Creative Director Notes** — Does this create the emotional experience we intended?
**4. Final Build Recommendation** — Exactly what gets built.

### The Institution Test

Before any page is approved, ask:
> If someone discovered this page twenty years from now — would it still feel true? Would it still represent Mapping With Melanin™? Would we still be proud of it?

## Global Design System Recommendations

*Pending "Please implement." — All items below are approved direction, not yet built.*

### Background Color System

Replace flat dark brown backgrounds with a warm directional gradient.

| Layer | Current | Recommended |
|-------|---------|-------------|
| Top Left | `#1C0E06` | `#331A0B` |
| Center | `#1C0E06` | `#2C170E` |
| Bottom Right | `#1C0E06` | `#221309` |

The eye naturally travels through the page. Hope becomes directional.

### Gold System

Current gold is flat. Replace with a three-stop gradient used only for headlines, key emphasis, icons, and dividers.

```
#E8C96D → #D6AE55 → #C09840
```

### Typography

- Chapter labels: increase from `0.85vw` to `0.95vw` — they become navigation, not decoration.
- Body copy: no wording changes. Improve readability through line height and spacing rhythm.
- Dimensional gold on all headlines. Subtle warm shadow.

### Icons

Increase every custom icon approximately 17%. Icons currently disappear visually. They should lead the eye.

### Bullet System

Replace every filled bullet `•` with gold outline circle `◌` — this becomes part of the Mapping With Melanin™ visual language.

### Page Numbers

**Remove all page numbers throughout the Legacy Collection.** Page numbers interrupt the editorial flow. The experience should feel continuous — like turning the pages of a designed book, not advancing a slide show.

### Phone Mockup Consistency

Every phone mockup must share:
- Same bezel
- Same shadow
- Same angle
- Same size
- Same lighting

This makes the entire Presentation System feel intentional.

### Background Transitions

The warm brown beginning of the deck has the right warmth. The cream transition needs refinement — it should feel earned, not abrupt. Think parchment, not white paper.

## Coffee Table Book Format

**Requested direction — pending "Please implement."**

The deck should feel less like a PowerPoint presentation and more like opening a beautifully designed book.

References:
- Tom Ford
- Apple
- Nike Brand Guidelines
- Airbnb Design Language

Not because we imitate them — but because they create calm confidence. The audience should never feel overwhelmed. Every page should breathe.

Key editorial shifts when implementing:
- White space becomes Sacred Space — not empty, intentional
- Evidence feels earned, not marketed
- Hope feels directional — lighting invites people forward
- Section dividers feel like entering a new volume, not a new slide
- Each chapter opening = entering another room in a designed space
