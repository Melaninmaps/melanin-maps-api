## Rule (PERMANENT)

When an interruption arrives mid-implementation (architectural clarification, new requirement, question, new file upload):

1. Address the concern directly and completely (answer questions, confirm architecture, flag gaps).
2. Immediately return to the active implementation list as if the interruption did not happen.
3. Do NOT wait for a second authorization message — the original "Please implement." remains active.
4. If the founder forgets we were mid-implementation, remind them: "We were on [stage] of the authorized implementation list — resuming now."

## Why

The founder works in long implementation sessions and interruptions are architectural clarifications, not stops. Waiting for re-authorization after every clarification wastes session time.

## Active phrase to watch for

"MAPPING WITH MELANIN™ — AUTHORIZED IMPLEMENTATION" = resume the in-progress implementation list immediately after addressing the concern.
